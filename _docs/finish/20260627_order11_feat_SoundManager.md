実装計画書に、ピンチBGMの音量制御（閾値とクロスフェード曲線）に関する以下のバランス調整仕様を追加し、ロジックを修正せよ。

### 追加要件：LIFE残量に基づく3段階の動的音量補間ロジック
これまでの「LIFE 15%以下でピンチ」という固定閾値を廃止し、以下の3つのポイント（40%、20%、0%）を基準としたクロスフェードおよびフェードアウト計算を `SoundManager.updatePinchVolume(lifeRatio, isMainPriority)` 内部に実装すること。

*   **定数の再定義**: `config.js` （または参照先）に以下の閾値を設定する。
    *   `PINCH_THRESHOLD_RATIO_MAX = 0.4` （40%）
    *   `PINCH_THRESHOLD_RATIO_MIN = 0.2` （20%）
*   **音量計算ロジック（isMainPriority === false の場合）**:
    1.  **lifeRatio >= 0.4**: メイントラック 1.0 / ピンチトラック 0.0
    2.  **0.2 <= lifeRatio < 0.4**: メイントラックを 1.0 から 0.0 へ、ピンチトラックを 0.0 から 1.0 へと線形補間（クロスフェード）させる。
    3.  **0.0 <= lifeRatio < 0.2**: メイントラック 0.0 / ピンチトラックは 1.0 から 0.0 へと線形補間（フェードアウト）させる。これにより、LIFEが0に近づくにつれて音が完全に消えゆく「熱的死（絶望）」を表現する。

この音量計算式を確実に適用したうえで、関連ファイルの改修（ステップ1〜5）をフルスロットルで完遂せよ。
