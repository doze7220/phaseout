# 実装指示書：RUBY BULLET改修：時止め早打ち・一斉破壊ロジック

ルビィの「RUBY BULLET」の演出仕様を「時止め（ステイシス）状態でのロックオン早打ちと、解除時の一斉破壊」として実装する。
パズルの進行に干渉させないための強力な安全網を構築せよ。

下記事項を守りつつ、実行してほしい。
また、実装にあたっては以下の【開発・運用ルール】を厳守すること。

### 【開発・運用ルール】
*   **マジックナンバーの禁止:** エフェクト、計算式などで係数・定数を使う場合は、かならずconfig.jsやeffectConfig.jsで定義を行うこと。ハードコーディングは絶対に禁止とする。ただしSkillManager.jsだけは例外とし、具体的な指示がない限りはモジュール内でマジックナンバー使用も許す。
*   **コンフィグのコメント義務化:** コンフィグに定義を行う場合は、必ずコメントを残すこと。

---

## 1. SkillManager.js へのステイシス早打ちロジックの実装
*   モジュール内に `activeSkillQueues = []` を定義せよ。
*   **`activateSkill(slotIndex)` の改修**:
    *   既存のゲージリセットとポップアップ表示は維持する。
    *   `effects.toggleStasisEffect(true)` を呼び出し、パズル時間を停止（ステイシス）せよ。
    *   `PhaseManager` 等を介して物理演算を停止（`isPuzzlePaused = true`）させ、プレイヤーのタップ入力がパズルに干渉しないよう状態をロックせよ。
    *   **【重要：ターゲット抽出と保護】** 盤面（`GameState.GEMS`）から `colorId !== skillData.excludeColorId` の宝石を抽出する。その際、**「現在チェイン中（レーザー照射中、あるいは消去待機中）の宝石」を必ず除外（フィルタリング）すること。**
    *   抽出した安全な宝石から最大 `effectValue` 個をランダムに選び、`activeSkillQueues` に登録せよ。

## 2. `update()` メソッドの新設とキューの進行
*   毎フレーム呼ばれる進行メソッドを新設せよ。（ステイシス中は `gameDelta` が0になるため、`realDelta` を用いてタイマーを進行させる等、止まらない工夫をすること）。
*   キューの進行（10フレームまたは約160ms間隔）：
    1.  指定間隔に達するごとにターゲットから宝石を1つロックオンする。
    2.  対象の座標に対して `effects.playSE('GUN')` を鳴らし、弾痕エフェクト（閃光やヒビ等、適切なパーティクル表現）をCanvasに描画せよ。（※この時点ではまだ `remove` による物理削除は行わない）
*   **解除と一斉破壊（キュー完了時）**:
    1.  全ターゲットへのロックオン（早打ち演出）が完了した直後、`effects.toggleStasisEffect(false)` と `isPuzzlePaused = false` で時止めと入力ロックを解除する。
    2.  ロックオンしていた全ての宝石を `Matter.Composite.remove` 等で一気に物理ワールドおよび `GameState.GEMS` から削除し、各座標で火花や破片エフェクト（`effects.spawnBurstSparks` 等）を一斉に発生させよ。（※スコア・チャージ加算フローへは流さない）。

## 3. physics.js 等へのループ結線と動作確認
*   `physics.js` または適切なグローバル更新ループにて、毎フレーム `SkillManager.update()` が呼ばれるよう結線せよ。
*   動作確認：ルビィのゲージMAX時、時が止まり（タップ不可）、銃声と共に弾痕が次々と刻まれ、時が動き出した瞬間に一斉に宝石が砕け散ることを確認せよ。
*   完了後、インデックス資料の更新を行うこと。
